# Crafted Emblem

Use when the app needs a memorable symbol, logo-adjacent mark, tool identity, or launch icon.

- Concept job: create one clear emblem tied to the product action.
- Structure: emblem or icon system plus readable editable copy and restrained supporting geometry.
- Good assets: SVG paths, Lucide/Iconify icons with license-safe source, shape layers, local logo.
- Avoid: unlicensed logo copying, vague abstract marks, overcomplicated symbols.
- Validation: emblem source is packaged or editable; source/license note is recorded when external icons are used.
