# Editorial Split

Use when the app needs clarity, trust, launch messaging, docs, editorial/news surfaces, or when repo evidence is light.

- Concept job: make the written promise feel authoritative.
- Structure: strong left or centered text zone, one deliberate visual object, restrained divider or rule system.
- Good assets: editable text, badge, paper/card surfaces, publication spread, route label, local logo.
- Avoid: generic dashboard widgets, unrelated abstract shapes, excessive glow.
- Validation: headline and subtitle are editable; the visual object has a named job; background does not carry important text.
