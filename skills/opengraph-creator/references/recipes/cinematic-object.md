# Cinematic Object

Use when the user wants dramatic, premium, fantasy, luxury, gaming, launch, or high-energy visual direction and image generation is available or repo assets can support it.

- Concept job: one hero object symbolizes the product outcome.
- Structure: large non-text visual asset, clear editable typography, controlled lighting, foreground/background depth.
- Good assets: generated non-text background/object, local product image, SVG highlight strokes, serialized lighting/vignette.
- Avoid: text inside generated art, random particles, muddy low-contrast effects.
- Validation: hero object is packaged as an asset; important text is editable; effects remain serialized or clipped.
