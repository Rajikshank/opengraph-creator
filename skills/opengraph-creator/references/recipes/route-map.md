# Route Map

Use for page-specific or hybrid OG systems where each route needs a distinct card inside one shared visual language.

- Concept job: show that every page is part of one app system.
- Structure: shared background/rule system, route-specific focal motif, route badge, export path per page.
- Good assets: editable page variants, route-specific badge/text, SVG map/path, shared brand layer IDs.
- Avoid: identical variants with only the title changed, disconnected visual styles per page.
- Validation: one `.ogdoc` contains internal page variants; every variant has route-specific text, motif, and exportPath.
