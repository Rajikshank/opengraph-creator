# .ogdoc Schema Reference

`.ogdoc` is the editable Studio source of truth. It stores project JSON, packaged assets, previews, and recovery metadata.

Keep headline, subtitle, badges, route labels, CTA text, logos, screenshots, source images, shapes, backgrounds, and decorative layers separately editable. Generated image assets may be rich, cinematic, or textured, but they must sit inside the document as assets beneath editable text and layout layers.

Do not use a flat image or one baked SVG as the master document unless the user explicitly chooses pure-image fallback after being warned that it reduces Studio editability.
